# Homebrew Tap

Homebrew packages maintained by [nikuscs](https://github.com/nikuscs).

## Wormhole CLI

Install:

```sh
brew install nikuscs/tap/wormhole
```

Upgrade:

```sh
brew upgrade wormhole
```

Uninstall:

```sh
brew uninstall wormhole
```

See [nikuscs/wormhole](https://github.com/nikuscs/wormhole) for documentation.

## scanr

Install:

```sh
brew install nikuscs/tap/scanr
```

Upgrade:

```sh
brew upgrade scanr
```

Uninstall:

```sh
brew uninstall scanr
```

Apple Silicon macOS and x86_64 Linux only. See [nikuscs/scanr](https://github.com/nikuscs/scanr) for documentation.
